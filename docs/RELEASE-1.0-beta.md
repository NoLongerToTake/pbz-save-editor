# 1.0 Beta 发布说明

首个公开测试版，适用于Windows x64。下载ZIP后完整解压，运行“PBZ存档编辑器.exe”，无需安装Python或Rust。

## 1. 功能

- 自动寻找存档、自定义存档和备份路径、保存前自动备份、完整备份恢复。
- 790种物品、14类分类，支持书籍、书页和剧情物品。
- 62项支线目录；51项有成功路线，29项可选择阶段。
- 完成、完成到阶段、失败、回退未接取、奖励预览与补发、联合撤销。
- 未改槽位保留密文，其他JSON原文和浮点文本尽量按局部编辑保留。

## 2. 验证

原版本161项自动测试通过；公开源码版161项中160通过、1项因未提供原始本地化证据跳过。

已执行实际Windows窗口测试。不灭侠胆已验证S1→1、最终奖励TU_19006×1、失败/回退/撤销、备份/恢复和重复领取判断。只对测试副本写入，没有改动正式存档。

## 3. 已知限制

- NPC、剧情、地图事件和材料交付暂不适配；回退任务记录不保证能重接任务。
- 目录条数不等于全部路线和奖励已适配；未核实奖励不会自动猜测补发。
- 数量奖励领取不明时需明确勾选确认；外部记录丢失或游戏再次保存后可能无法确认历史。
- 游戏内载入效果尚未验证。首次使用建议另存，检查任务和奖励后再决定是否替换正式存档。
- 这是Beta测试版，预发布标记会在GitHub中保留。
